# Vera brand files

Written by `apps/panel/scripts/render-brand.mjs` (see the top of that file
to run it). Edit the script, not these files.

| File | Use |
|---|---|
| vera-mark.svg | The mark on light backgrounds |
| vera-mark-on-dark.svg | The mark on dark backgrounds |
| vera-mark-black.svg, vera-mark-white.svg | One colour, where lime can't be used |
| vera-lockup.png, vera-lockup-on-dark.png | Mark and wordmark, transparent, 2x |
| vera-avatar-light-*.png, vera-avatar-dark-*.png | Profile pictures (400 and 1024 px) |
| icon-192.png, icon-512.png | App icons |
| og.png | Link preview, 1200 x 630 |

The tab icon (app/icon.svg, app/favicon.ico) and the home-screen icon
(app/apple-icon.png) live in app/, where Next serves them.

Colours: ink #0B0B0B, lime #C9F23C, white #FFFFFF. Lime is always a fill,
never text. Keep clear space around the mark of at least the lime square's
width.
