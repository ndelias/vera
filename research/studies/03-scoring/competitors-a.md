# Competitor scan A: AI code, review, agents, comprehension, context, approvals

Web research by a Claude Code research agent on 2026-10-20 (public pages
only). "Vendor" marks claims the vendors make about themselves. Pricing
changed often in 2026; much of it comes from third-party trackers.

| Pain | Main tools | Judgment |
|---|---|---|
| AI-written code needs cleaning up | CodeRabbit ($24–72/user), SonarQube AI Code Assurance, Codacy Guardrails, Snyk Code, Qodo ($30) | **(c) Partial.** Detection is plentiful (Veracode 2026: AI code passes security checks 56% of the time). Nothing stops slop being produced or does the rework |
| Overloaded code review | CodeRabbit, Greptile ($30 + usage), Cursor Bugbot, GitHub Copilot code review, Graphite (bought by Cursor Dec 2025), Claude Code Review, Sentry Seer | **(b) Well served for the bot first pass.** The core problem, how much human reviewers can get through, is unaddressed. Bots add comments; 93.4% of flagged locations were caught by only one of four bots in a 146-PR test |
| Supervising coding agents | GitHub Agent HQ, Cursor 3 Agents Window, Conductor, Vibe Kanban, Devin, Slack Code | **(c) Fragmented.** Dashboards start and display agent work. Little helps you trust what an agent did unattended |
| Nobody understands the code | DeepWiki, Sourcegraph Deep Search, Unblocked, Augment Context Engine, PR walkthroughs (CodeRabbit, Greptile) | **(d) Tools miss the core.** They explain code when asked. None makes sure a person understood a change before it merged (Anthropic RCT: AI group scored ~50% vs 67% on comprehension) |
| AI tools lack the team's context | Rules files (AGENTS.md, CLAUDE.md), Augment Context Engine MCP, Unblocked, Tessl, CodeRabbit Learnings, Sourcegraph | **(c) Partial.** Context can be loaded easily. Nothing reliably makes agents follow it. Studies are mixed on whether context files help |
| Approvals across roles stall work | CODEOWNERS, Aviator FlexReview, LinearB gitStream, Chromatic UI Review, preview environments | **(d), close to (e).** Tools route approvals between engineers. Nothing coordinates design, security and product sign-off together |

Evidence on review load (vendor data): Faros links high AI adoption with
~51% larger PRs and median review time up 441%. LinearB reports AI-assisted
PRs past 400 lines at the 75th percentile, and agentic PRs waiting 16+ hours
for pickup.
