# Competitor scan B: tech debt, knowledge, interruptions, tools, requirements, eng-dependency

Web research by a Claude Code research agent on 2026-10-20 (public pages
only). Claims marked "vendor" or "unverified" come from vendors or
aggregators. Summary of the agent's report. Full source list at the end.

| Pain | Main tools | Judgment |
|---|---|---|
| Tech debt never prioritised | SonarQube, CodeScene, Stepsize, Jellyfish, LinearB, DX | **(d) Tools miss the core.** Measuring debt is commoditized. No tool turns it into a business case that wins roadmap trade-offs |
| Knowledge in people's heads | Confluence + Rovo, Notion, Glean, Guru, Swimm, DeepWiki | **(c) Partial.** Search over existing docs is well served, at enterprise prices. Capturing what's in people's heads and keeping it current isn't |
| Interruptions | Reclaim, Motion, Geekbot, Slack/Outlook built-ins (Clockwise reportedly shut down Mar 2026) | **(d) Tools miss the core.** Calendars are covered. Ad-hoc pings and tool switching (the frictions developers rank highest) are barely addressed |
| Too many tools | Jira, Linear, ClickUp, Notion, Unito, Zapier/Make, Rovo/Glean | **(d) Tools miss the core.** Every fix is another tool (a suite or a sync layer). Fitting tools to the team's own process isn't addressed |
| Vague/changing requirements | ChatPRD, Productboard, Jira Product Discovery, Notion AI, Kiro, GitHub Spec Kit | **(d) Tools miss the core.** Tools speed up writing specs. None track why requirements change or check shipped code against the spec |
| Non-engineers depend on engineering | Headless CMSs (Contentful), Builder.io, LaunchDarkly, Figma Make, Lovable, Claude Code/Cursor used by PMs | **(c) Partial.** Copy is close to solved through a CMS. UI tweaks now reach a PR, but every change still waits on an engineer to review and merge it |

Context: Atlassian's 2025 developer-experience report (n=3,500) found 50%
lose 10+ hours a week to non-coding work. The top frictions were finding
information and switching between tools.
